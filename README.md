# Jewellery Stall Website

This version includes your four jewellery photos.

## Files
- `index.html`
- `style.css`
- `script.js`
- `images/` — contains the four product photos

## GitHub Pages
Upload **all of these files and the entire `images` folder** into the root of your GitHub repository. Keep the `images` folder name unchanged.

Then go to **Settings → Pages** and choose:
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

Your website will then be published with GitHub Pages.
